01 / WHY

不再逐页盯着找问题。
先让异常自己浮出来。

一本技术手册可能有几十到几百页。字体、箭头、图注、页码和模板标签之间的细小错误， 很容易在长时间人工检查中被忽略。

这套 Skill 将页面拆成独立任务并行审查，再把高风险发现交回本地 Agent， 对照原始全分辨率页面逐项确认。模型的判断是线索，不是事实。

03 / DETECTION

小问题，
也要有证据。

审查结果必须指向页面、区域与可观察现象。没有位置、没有证据、无法回到原图复现的结论， 不进入最终报告。

04 / RESPONSIBILITY

模型提案，证据定案

避免“模型说有问题，所以就有问题”。

LOOMLOOM CLOUD

高召回地发现异常

  • 批量并行检查书页截图
  • 提出问题位置与视觉原因
  • 给出严重度和修改线索
  • 返回结构化审查结果
发现 → 复核

LOCAL AGENT

回到原图完成裁决

  • 拒绝页面身份不匹配的返回
  • 核对坐标、引文和视觉因果
  • 记录接受、改写与误报
  • 输出可复查的最终报告
