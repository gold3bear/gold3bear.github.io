真实案例

百里挑一选好股：从一句话，到一个已上架的商品

一个段永平式价值投资初筛工具。批量投进几十上百只美股，云端四维并行审查，本地校验器把站不住的结论一条条拒掉——最后留下的，才值得你花时间深研。

你只给一串股票代码。本地 Agent 把它们整理成三份可追溯的数据包——身份与来源、 财务与估值、商业质量与风险——交给公开 SkillBot 并行审查，再由本地校验器逐条核对： 来源路径解析不了、原值对不上、期间过期的，一律拒绝，不参与排名。 从一句话的想法到能被别人安装付费使用的产品，全程没写一行代码。

  • 六维加权：商业模式、护城河、财务质量各 20%，估值、资本配置各 15%，能力圈 10%
  • 九条强制否决，任一触发即不得进入深度研究
  • 结果分四档交付：deep_research / watchlist / pass / rejected
  • 已作为公开 SkillBot 上架 Market，按任务固定计费
  • 已发布 GitHub Release、可安装 Skill 与营销传播页面
  • 适配 Workbuddy、Codex、Claude Code、OpenClaw
